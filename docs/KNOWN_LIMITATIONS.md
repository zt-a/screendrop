# Known Limitations

1. **Hotspot routing:** смартфон-хост не всегда может обращаться к подключённому Android-экрану. Проверять каждую пару устройств.
2. **Client isolation:** общий Wi-Fi может блокировать прямую связь между клиентами.
3. **HTTP:** не шифрует файл и токен.
4. **Android background limits:** система может завершать фоновые процессы; в текущем MVP сервер работает, пока приложение открыто на экране (экран не гаснет через FLAG_KEEP_SCREEN_ON). Foreground Service — вне сессии MVP.
5. **Document viewer:** открытие зависит от установленного приложения на устройстве-приёмнике.
6. **Formats:** разрешённое расширение не гарантирует поддержку viewer.
7. **Storage:** объём зависит от свободного места устройства.
8. **Платформа:** целевое устройство — Android-экран (планшет / сенсорная панель / Android TV). UI touch-first; D-pad поддерживается базово через фокус Compose, но глубокая TV-навигация не тестировалась.
9. **Не входит в MVP:** облако, аккаунты, админ-панель, TLS, автообнаружение, resumable uploads, централизованное управление.

Не заявлять универсальную совместимость или абсолютную безопасность без доказательств.
