## Нефункциональные требования
- NFR-001: сеть и файловый I/O не выполняются на Main Thread.
- NFR-002: RAM ограничена потоковой обработкой.
- NFR-003: ошибка клиента не останавливает сервер.
- NFR-004: готовый файл виден только после успешной финализации.
- NFR-005: операции управления требуют действительной сессии.
- NFR-006: файлы не отправляются сторонним сервисам.
- NFR-007: минимальный Android API определяется после обследования TV.
- NFR-008: TV UI читаем и управляется D-pad.
- NFR-009: ошибки сети диагностируются раздельно.

Вне MVP: облако, аккаунты, централизованная панель, автообнаружение, TLS, resumable uploads.
