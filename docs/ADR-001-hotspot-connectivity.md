# ADR-001: Hotspot connectivity gate

**Статус:** Accepted | **Дата:** 2026-11-11

## Контекст
Сценарий: телефон создаёт Hotspot, TV подключается, браузер того же телефона открывает HTTP server TV. Это может быть ограничено маршрутизацией конкретной реализации tethering.

## Решение
До полного UI реализовать PoC:
1. TV запускает HTTP server.
2. TV показывает IPv4.
3. Телефон включает Hotspot и подключает TV.
4. Браузер телефона выполняет GET к TV.
5. Выполняется POST тестового файла.

## Критерий
Успешные GET и POST с физического телефона на физический TV без внешнего интернета.

## Если не работает
Проверить bind/IP/firewall/маршрут; проверить другой телефон; проверить existing Wi-Fi; зафиксировать несовместимость; рассмотреть Phone Transfer Hub отдельно.
