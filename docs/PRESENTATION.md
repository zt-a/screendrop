# Презентация ScreenDrop — 10 слайдов

1. **Название:** локальная передача файлов на Android-экраны по QR.  
   Речь: система упрощает отправку документов на экран аудитории.
2. **Проблема:** мессенджеры, USB, облака и лишние действия.  
   Речь: передача часто занимает больше времени, чем должна.
3. **Решение:** локальный сервер TV и браузерный sender.  
   Речь: экран становится приёмником файлов.
4. **Архитектура:** Browser → TCP/IP → Ktor → Upload Engine → Storage.  
   Речь: TV — сервер, браузер — клиент.
5. **Сеть:** Wi-Fi, IP, TCP, HTTP.  
   Речь: интернет не нужен при наличии локальной IP-связности.
6. **Передача:** multipart, streaming I/O, SHA-256.  
   Речь: данные записываются потоково и проверяются хешем.
7. **Безопасность:** временные токены, лимиты, private storage.  
   Речь: HTTP не шифрует трафик — это ограничение MVP.
8. **Демонстрация:** Hotspot → QR → Upload → PDF на TV.
9. **Стек:** Kotlin, Android SDK, Ktor, Coroutines, Compose, HTML/CSS/JS.
10. **Результат:** локальная передача без облака; перспективы — desktop и управление аудиториями.
