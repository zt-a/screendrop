# Вопросы к защите

1. **Почему это системное программирование?** Приложение использует системные сетевые интерфейсы, TCP-сокеты через HTTP server, файловую систему, Service lifecycle, потоки и асинхронный I/O.
2. **Что такое TCP?** Транспортный протокол, предоставляющий надёжный упорядоченный поток байтов.
3. **TCP vs UDP?** TCP обеспечивает соединение, порядок и повторную передачу; UDP отправляет датаграммы без встроенной гарантии доставки.
4. **Что такое IP?** Протокол адресации и маршрутизации пакетов.
5. **Что такое порт?** Числовой идентификатор транспортного endpoint.
6. **Что такое socket?** Программный сетевой endpoint.
7. **Что такое HTTP?** Прикладной протокол запросов и ответов поверх TCP в MVP.
8. **Почему не нужен интернет?** Данные идут по локальной IP-сети, если есть маршрутизация.
9. **Что такое локальная сеть?** Сеть устройств в ограниченной области, не требующая обязательного выхода в интернет.
10. **Как работает QR?** Содержит локальный URL и временный token.
11. **Что такое multipart?** Формат HTTP body для нескольких частей, например файла и полей.
12. **Что такое streaming I/O?** Обработка блоками, а не загрузка всего файла в память.
13. **Почему не загружать весь файл в RAM?** Большой файл может исчерпать память.
14. **Что такое SHA-256?** Хеш-функция, формирующая 256-битный digest.
15. **SHA-256 шифрует?** Нет, это хеширование, а не шифрование.
16. **Как защищён upload?** Session token, лимиты, проверка имени, private storage и временная запись.
17. **Что такое Path Traversal?** Попытка выйти из разрешённого каталога через путь вроде `../`.
18. **Что при разрыве сети?** Upload не финализируется, temp file удаляется, состояние сети обновляется.
19. **Что такое ConnectivityManager?** Android API для информации о сетях и callback.
20. **Что такое NetworkCallback?** События о доступности и изменении сети.
21. **Что такое Android Service?** Компонент для операций без UI Activity; длительная работа может требовать Foreground Service.
22. **Почему Hotspot может не работать?** Производитель может ограничивать host-to-client routing или client communication.
23. **Почему QR локально работает, а с телефона нет?** Локальный bind не гарантирует маршрутизацию и доступ с клиента.
24. **Что такое файловый дескриптор?** Идентификатор открытого ресурса ОС, используемый файловыми потоками.
25. **Как обрабатывается concurrency?** Semaphore/лимит активных uploads; при превышении — 429.
26. **Почему temp file?** Чтобы неполный upload не считался готовым.
27. **HTTP безопасен?** Не шифрует данные; token не защищает от перехвата.
28. **Как масштабировать?** Desktop app, mDNS/NSD, multi-room и Phone Transfer Hub.
29. **Где файлы?** В приватном каталоге Android-приложения.
30. **Практическая ценность?** Отправка документов на экран без личных мессенджеров и облака.
