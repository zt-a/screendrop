# ADR-003: Streaming upload

**Статус:** Accepted

Файлы принимаются потоково: multipart stream читается блоками, данные записываются во временный файл, SHA-256 обновляется теми же байтами. После успешного завершения файл финализируется. При ошибке temp file удаляется.

Причина: ограниченная RAM Android TV и необходимость не публиковать неполные файлы.
