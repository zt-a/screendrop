# User Guide

## Преподаватель
1. Убедиться, что ScreenDrop установлен на Android TV.
2. Подключить TV к Wi-Fi или Hotspot.
3. Запустить ScreenDrop.
4. Нажать Start Receiving.
5. Дождаться статуса сервера и QR.
6. Показать QR студенту.
7. После upload открыть Received Files.
8. Выбрать документ и нажать Open.
9. В конце занятия закрыть сессию.

## Студент
1. Подключиться к указанной сети.
2. Отсканировать QR камерой.
3. Выбрать файл в браузере.
4. Нажать Upload.
5. Дождаться результата.

Установка приложения на смартфон не требуется.

## Если QR не открывается
Проверить сеть, READY, IP и порт. Попросить преподавателя обновить QR. Возможно, Hotspot или Wi-Fi изолирует устройства. Использовать другой проверенный сетевой режим.

## Ограничение
HTTP в MVP не шифрует содержимое. Не отправлять конфиденциальные документы через недоверенную сеть.
