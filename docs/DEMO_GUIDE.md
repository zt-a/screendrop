# Demo Guide

## Подготовить
Android TV с APK, смартфон с Hotspot, PDF небольшого размера, заряженные устройства, проверенную пару устройств и резервную Wi-Fi сеть.

## Live demo
1. Включить Hotspot.
2. Подключить TV.
3. Запустить ScreenDrop.
4. Показать network status и QR.
5. Отсканировать QR.
6. Выбрать PDF.
7. Отправить.
8. Показать progress.
9. Показать файл в Received Files.
10. Открыть PDF.
11. Показать SHA-256.

## Объяснить
TV запускает HTTP server; browser — client; TCP предоставляет надёжный поток; multipart передаёт файл; streaming I/O не загружает всё в RAM; SHA-256 проверяет целостность; token ограничивает доступ.

## Резерв
Если Hotspot не обеспечивает доступ, показать диагностику, подключить оба устройства к заранее проверенной общей Wi-Fi сети и повторить. Не выдавать запись экрана за live demo.

Для демонстрации работы без интернета отключить WAN/mobile data, но сохранить локальную Wi-Fi сеть.

## Не заявлять
Не утверждать поддержку всех TV, шифрование HTTP или тестирование устройств, которые не проверялись.
